# Hospice Dash

A beginner-friendly browser runner, created by Inology IT.

## Play

Open `index.html` in a browser with an internet connection. Phaser loads from a CDN; no installation, build step, or API key is needed.

- Press Space, click, or tap to jump.
- Jump over planters, hedges and hurdles.
- Stay on the ground beneath branches and hanging lamps.
- Select Run again after a collision.
- Best scores are saved only in your browser.

## Files

- `index.html`: page, buttons and creator credit.
- `styles.css`: colours, layout and mobile styling.
- `src/game.js`: gameplay, artwork and running animation. Change SETTINGS at the top to adjust difficulty.
- `assets/inology-it.png`: supplied Inology IT logo.
- `.nojekyll`: serves the files directly through GitHub Pages.
- `.gitignore`: excludes private settings and unnecessary files.
